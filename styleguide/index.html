Headings: Source Sans 3 (sans-serif). Body: Merriweather (serif). Both self-hosted under SIL OFL. Use the language toggle at the top to preview English, French, and Spanish.

13. Accessibility

Focus states

Tab through the components below using your keyboard. Every interactive element shows a 3px burnt-orange outline with 2px offset. The focus ring is defined once in tokens.css as --focus-ring.

Focusable link

Skip link

Press Tab when this page has focus — the skip-to-content link appears as the first focusable element and jumps past navigation to the main content.

Screen reader markup

The module list above is wrapped in <ul aria-label="Module list"> so screen readers announce "list of N items." Progress bars use role="progressbar" with aria-valuenow, aria-valuemin, and aria-valuemax. Error messages use role="alert". Toasts use aria-live="polite".

Text size toggle

The A-/A/A+ buttons in the top nav swap the --font-size-base token between 16px, 20px, and 24px by adding a class to <html>. The preference persists in localStorage under the key dcc-text-size.

Motion preferences

Every transition in components.css references --motion-duration-* tokens. tokens.css zeros them out inside @media (prefers-reduced-motion: reduce), so nothing needs a per-component override.

Contrast testing checklist

  • Text on background: 4.5:1 minimum (WCAG AA) — verified for text on bg, surface, and surface-primary.
  • Large text (18pt+): 3:1 minimum.
  • Interactive element borders: 3:1 against adjacent colour.
  • Focus ring: 3:1 against every background it appears on.

Browser testing

Before each release: keyboard-only nav test, screen reader test (NVDA on Windows), 200% zoom test, high contrast test, reduced motion test, axe-core automated scan.
