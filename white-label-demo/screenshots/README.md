# Screenshots Directory

This folder contains screenshots of the white-label demo site for use in sales presentations and proposals.

## How to Take Screenshots for Client Presentations

1. Open `white-label-demo/index.html` in Chrome or Firefox
2. Press **F11** to enter fullscreen mode
3. Take a screenshot using:
   - **Windows:** Win + Shift + S (Snip & Sketch)
   - **Mac:** Command + Shift + 4
   - **Chrome:** Three dots → More tools → Developer Tools → Toggle device toolbar (Ctrl+Shift+M) → Choose iPad Pro → Screenshot
