Keyboard Shortcuts

← Back to Accessibility Statement

This page lists all keyboard shortcuts available on the Digital Confidence Centre website. You do not need to use a mouse or touchscreen — you can navigate the entire site using only a keyboard.

Navigation

Key Action
Tab Move forward to the next link, button, or form field
Shift + Tab Move backward to the previous interactive element
Enter Activate a focused link or button
Space Activate a focused button or check a checkbox
↑ ↓ Navigate search results or dropdown lists
Home / End Jump to the top or bottom of the page

Page Shortcuts

Key Action
/ Open the search box from anywhere on the page
Escape Close modals, menus, or the search dropdown
Tab (at the very start of a page) Reveals the "Skip to main content" link — press Enter to bypass navigation
Enter (on an accordion heading) Expand or collapse the accordion section

Quizzes and Exercises

Key Action
Tab Move between answer options
Enter or Space Select a highlighted answer option
Enter (on Next/Submit button) Submit your answer or move to the next question

Accessibility Bar

The accessibility bar at the top of every page contains buttons for the following. Each button can be reached by keyboard using Tab and activated with Enter or Space.

  • A (six sizes) — change the text size: Small, Medium, Large, Extra Large, XXL (140% base), XXXL (160% base)
  • ⏸ (Reduce animations) — disable all transitions and animations across the site
  • 📖 (Reading guide) — highlight the paragraph or list item your pointer is resting on
  • ◐ (High contrast) — increase colour contrast across the whole page
  • 👓 (Dyslexia-friendly font) — switch to OpenDyslexic font
  • 🌓 / ☀️ (Dark/Light mode) — switch between dark and light colour schemes

All accessibility preferences are saved automatically. They will be remembered the next time you visit.

Tips for Keyboard Users

  • Use Tab to move through the page in order. You will see a blue outline on the element that has focus.
  • If you get lost, press Escape first — it closes overlays and returns focus to a known position.
  • The search box shortcut (/) works unless your focus is already inside a text field.
  • To use the navigation menu with a keyboard, press Tab until the menu button (☰) is highlighted, then press Enter to open it.
