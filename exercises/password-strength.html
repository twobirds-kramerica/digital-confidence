Practice Exercise: Password Strength

Practice creating strong passwords without using any real passwords. Everything stays on your device — nothing is sent anywhere.

Start typing to check strength

  • At least 8 characters long
  • Contains a capital letter (A, B, C…)
  • Contains a lowercase letter (a, b, c…)
  • Contains a number (1, 2, 3…)
  • Contains a symbol (!, @, #, $…)
💡

Remember: A strong password is long, random, and unique to each account. Consider using a password manager to create and remember strong passwords for you.
