Scam Detective: Can You Spot the Trick?

Read each message carefully and decide: is it a scam or is it safe? You have 20 seconds per question. Don't worry — no real personal information is involved.

How to play:

You will see 5 real-world messages — texts, emails, and phone call scripts. For each one, press This is a Scam or Looks Safe before the timer runs out. After each answer, you'll see an explanation with the red flags to watch for.

Ready to start? Your 20-second timer begins with the first question.

🔍

Remember: Real government agencies like the CRA never threaten arrest or demand immediate payment. If something feels urgent or scary — that's a scam tactic. Hang up. Delete. Call someone you trust.
