# DCC Thumbnail Templates — Specification Guide

Digital Confidence Centre | 16 Module Series
For use with Canva, Adobe Express, or any graphic design tool

---

## Global Specifications

| Property | Value |
|---|---|
| Dimensions | 1280 × 720 pixels |
| Colour mode | RGB |
| Resolution | 72 DPI (screen only) |
| File format | PNG or JPG, max 2MB for YouTube |
| Font family | Open Sans (Bold for headline, Regular for subtext) |

## Required Elements (All Thumbnails)

Every thumbnail must include:

1. **DCC Logo** — bottom-right corner, white version, 120px wide
2. **Module Number Badge** — circle badge, top-left, colour matches palette, white number inside, 80px diameter
3. **Headline Text** — maximum 8 words, 72pt Bold, high-contrast
4. **Sub-text** — 32pt Regular, below headline, shorter phrase
5. **Background** — solid colour, gradient, or simple pattern — no photographic backgrounds (too busy)
6. **Colour-coded left accent bar** — 20px wide vertical bar on left edge in module's accent colour

## Notes for Graphic Designers

### Using Canva
1. Start with a blank 1280 × 720 canvas
2. Add a solid fill background in the module's palette colour
3. Add the 20px left accent bar as a rectangle element
4. Add the circular module badge: use a circle shape, fill with badge colour, white number text centred inside
5. Add headline text: Open Sans Bold, 72pt, white, left-aligned (with 60px left margin)
6. Add sub-text: Open Sans Regular, 32pt, white or light mint, below headline
7. Add icon/illustration: keep it simple, use Canva's free icon library (search for the concept, not a specific brand)
8. Add DCC logo (white version) to bottom-right corner, 120px wide
9. Export as PNG, 1280 × 720

### Checklist Before Exporting
- [ ] Text is readable at 200px width (zoom out in Canva to check)
- [ ] Module number badge is clearly visible
- [ ] DCC logo in bottom-right corner
- [ ] No text runs off the edge (allow 60px margin on all sides)
- [ ] Colour matches the module's assigned palette
- [ ] No copyrighted brand logos reproduced exactly
