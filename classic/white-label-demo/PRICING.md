## Frequently Asked Questions

**Q: Do we need to pay for hosting separately?**
A: No. GitHub Pages and Cloudflare Pages both have free tiers that work perfectly for static sites. We set this up as part of onboarding.

**Q: What happens at the end of the licence year?**
A: You can renew at the same rate or a negotiated rate. The site continues to function even if you do not renew — content doesn't disappear. However, you would not receive updates or support.

**Q: Can we host it on our own servers?**
A: Yes. The site is pure static HTML/CSS/JS — it runs on any web server, shared hosting, or cloud platform. No special configuration required.

**Q: What if we need more than 3 custom modules?**
A: Additional modules are available at $3,500 each. Volume discounts available for 5+ modules.

**Q: Is the French content included?**
A: Modules 1–6 are currently available in French (Québécois/Ontario French). The remaining modules are in English only. Full French translation is available as an add-on or included in Tier 3.

**Q: How is user data handled?**
A: The site uses localStorage (browser-based) for progress tracking only. No user data is transmitted to any server. Feedback is sent through Formspree (configurable to your own endpoint). Fully PIPEDA/PHIPA compliant.
