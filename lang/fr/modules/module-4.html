Module 4 : Sécurité des Applications

Ce que vous allez apprendre : Comment trouver et télécharger des applications sécurisées, repérer les fausses applications, comprendre les permissions et gérer les abonnements — sans mauvaises surprises.

L'histoire de François

François, 76 ans, voulait télécharger une application météo pour son iPad. Son ami lui en avait recommandé une, alors François a ouvert ce qu'il pensait être l'App Store et a cherché « météo ». Il a trouvé une application qui semblait correcte, a tapé « Obtenir » et a immédiatement été invité à entrer son numéro de carte de crédit. François l'a entré, pensant que c'était normal.

Deux semaines plus tard, François a remarqué un débit de 49,99 $ sur sa carte de crédit d'une entreprise qu'il n'avait jamais entendue. Il s'avérait qu'il avait téléchargé une fausse application météo qui l'avait inscrit à un abonnement hebdomadaire. L'« App Store » qu'il avait utilisé était en fait un site Web se faisant passer pour l'App Store.

L'erreur de François était compréhensible — le faux magasin semblait très réel. Mais il existe des façons claires de s'assurer qu'on utilise le vrai App Store, qu'on télécharge de vraies applications et qu'on n'est jamais trompé par des frais cachés. C'est de cela que parle ce module.

Conseil

La façon la plus sûre d'ouvrir l'App Store est de taper directement sur son icône sur votre écran d'accueil — jamais depuis un lien dans un courriel, un message texte ou un site Web.

Le vrai App Store : Comment le trouver

L'App Store est le seul endroit sûr pour télécharger des applications sur votre iPad ou iPhone. Il est géré par Apple, et chaque application qu'il contient a été vérifiée pour sa sécurité. Voici comment trouver le vrai :

Trouver et ouvrir l'App Store

1 Cherchez sur votre écran d'accueil une icône bleue avec une lettre « A » blanche faite de lignes (comme des bâtons arrangés en forme de A). C'est l'App Store.
2 Tapez une fois dessus pour l'ouvrir.
3 Vous verrez un écran avec des applications recommandées, des catégories et une barre de recherche en haut.
Important

Ne téléchargez jamais des applications depuis un site Web, un lien dans un courriel ou un lien dans un message texte. Utilisez uniquement l'App Store officiel sur votre appareil. Si quelqu'un vous envoie un lien pour télécharger une application, ignorez-le — trouvez vous-même l'application dans le vrai App Store.

💛

Vérification de confiance : L'App Store est votre centre commercial sécurisé pour les applications. Si vous vous en tenez à l'App Store, vous êtes déjà en avance.

Comment télécharger une application

Télécharger une application étape par étape

1 Ouvrez l'App Store (icône bleue avec « A » blanc).
2 Tapez sur l'onglet Rechercher en bas de l'écran (il ressemble à une loupe).
3 Tapez sur la barre de recherche en haut et tapez le nom de l'application que vous voulez. Par exemple, tapez « MétéoMédia ».
4 Une liste de résultats apparaîtra. Avant de télécharger quoi que ce soit, vérifiez attentivement l'application (voir la liste de vérification ci-dessous).
5 Quand vous trouvez la bonne application, tapez le bouton bleu « Obtenir » (pour les applications gratuites) ou le bouton de prix (pour les applications payantes).
6 Confirmez avec Face ID ou votre code d'accès.
7 L'application se téléchargera et apparaîtra sur votre écran d'accueil. Vous pouvez taper dessus pour l'ouvrir.

Comment distinguer une vraie application d'une fausse

Quand vous cherchez dans l'App Store, vous pourriez voir plusieurs applications avec des noms similaires. Voici comment choisir la vraie :

  • Vérifiez le nom du développeur. Le nom du développeur apparaît sous le nom de l'application en petits caractères. Par exemple, la vraie application « RBC Mobile » est faite par « Royal Bank of Canada ». Si le nom du développeur vous semble inconnu ou mal orthographié, soyez prudent.
  • Regardez le nombre d'évaluations. Les applications populaires et légitimes ont des milliers ou des millions d'évaluations. Un clone peut en avoir très peu — peut-être des dizaines, voire aucune.
  • Lisez la note en étoiles. La plupart des vraies applications d'entreprises établies ont des notes de 3,5 étoiles ou plus (sur 5). Des notes très basses (en dessous de 2 étoiles) sont un signe d'avertissement.
  • Vérifiez les captures d'écran. Faites défiler vers le bas pour voir des images de l'aspect de l'application. Ont-elles l'air professionnelles ?
  • Repérez l'étiquette « Achats intégrés ». Si une application dit « Achats intégrés » sous le bouton « Obtenir », cela signifie que l'application est gratuite à télécharger mais peut vous demander de payer pour des fonctionnalités supplémentaires à l'intérieur.
⚠️

Vraie application vs application copie

Une vraie application bancaire est publiée par la banque elle-même et compte des millions de téléchargements. Une copie utilise un nom et un logo similaires mais provient d'un développeur inconnu avec très peu d'évaluations.

La Règle des 3 Secondes pour les applications

✋ Arrêtez Avant de taper « Obtenir », faites une pause et vérifiez les détails.
🫁 Respirez Il n'y a pas de précipitation. L'application sera encore là dans cinq minutes.
🔍 Vérifiez Vérifiez le développeur, les évaluations et les avis. Est-ce que tout semble correct ?
Attention

Si une application a très peu d'évaluations, un nom de développeur que vous ne reconnaissez pas, ou des captures d'écran qui semblent peu soignées, ne la téléchargez pas. Une vraie application d'une grande entreprise aura toujours des milliers d'évaluations.

Comprendre les permissions des applications

Lorsque vous ouvrez une nouvelle application pour la première fois, elle pourrait demander la permission d'accéder à des parties de votre iPad. Ces demandes apparaissent sous forme de petites fenêtres contextuelles. Voici ce que les plus courantes signifient :

  • « [Application] aimerait vous envoyer des notifications » — L'application veut vous envoyer des alertes et des rappels, même quand vous ne l'utilisez pas. Tapez « Autoriser » si vous voulez des rappels ou « Ne pas autoriser » si vous ne voulez pas être dérangé.
  • « [Application] aimerait accéder à votre localisation » — L'application veut savoir où vous êtes. Une application météo ou de cartographie en a besoin pour fonctionner. Un jeu ou une application de lampe de poche n'en a pas besoin. Choisissez « Lors de l'utilisation » pour les applications qui ont vraiment besoin de votre localisation.
  • « [Application] aimerait accéder à vos photos » — L'application veut voir les images stockées sur votre iPad. Une application de retouche photo en a besoin ; une calculatrice non.
  • « [Application] aimerait accéder à vos contacts » — L'application veut voir votre carnet d'adresses. Autorisez cela uniquement pour les applications de communication comme FaceTime ou Messages.
  • « [Application] aimerait vous suivre » — L'application veut suivre ce que vous faites sur d'autres applications et sites Web pour vous montrer des publicités ciblées. Presque toujours, tapez « Demander de ne pas suivre ».
La règle simple

Si vous n'êtes pas sûr, choisissez « Ne pas autoriser ». Vous pouvez toujours changer d'avis plus tard dans Réglages. Dire « non » ne casse jamais une application — au pire, une fonctionnalité pourrait ne pas fonctionner, et l'application vous le dira.

Abonnements et coûts cachés

Certaines applications sont gratuites à télécharger mais facturent des frais mensuels ou annuels pour continuer à les utiliser. C'est ce qu'on appelle un abonnement. C'est comme un abonnement à une revue — vous payez régulièrement pour continuer à la recevoir.

Les abonnements ne sont pas nécessairement mauvais, mais vous devez toujours savoir à quoi vous vous inscrivez. Voici comment vérifier :

Vérifier vos abonnements

1 Ouvrez Réglages (l'icône des engrenages gris).
2 Tapez sur votre nom en haut.
3 Tapez sur « Abonnements ».
4 Vous verrez une liste de tous les abonnements actifs. Si vous voyez quelque chose que vous ne reconnaissez pas ou ne voulez plus, tapez dessus et choisissez « Annuler l'abonnement ».
Attention

Certaines applications offrent un « essai gratuit » qui se transforme automatiquement en abonnement payant après 3 ou 7 jours. Si vous essayez un essai gratuit, définissez un rappel sur votre téléphone pour annuler avant la fin de l'essai — ou annulez immédiatement après vous être inscrit (vous bénéficierez quand même de toute la période d'essai, mais vous ne serez pas facturé par la suite).

Supprimer des applications que vous ne voulez plus

Supprimer une application de votre iPad

1 Trouvez l'icône de l'application sur votre écran d'accueil.
2 Appuyez et maintenez l'icône pendant environ deux secondes. Les icônes commenceront à osciller.
3 Vous verrez un petit « X » ou un signe moins dans le coin de chaque application. Tapez dessus sur l'application que vous voulez supprimer.
4 Tapez sur « Supprimer l'app » pour confirmer. (Si vous changez d'avis, vous pouvez toujours la télécharger à nouveau depuis l'App Store.)
5 Appuyez sur le bouton Accueil (ou tapez « OK ») pour arrêter l'oscillation.

Rappel : supprimer une application n'annule pas un abonnement. Si vous payez une application mensuellement, vous devez annuler l'abonnement séparément (en utilisant les étapes ci-dessus) avant de supprimer l'application.

🌟

Vous devenez un acheteur d'applications averti. Vous savez comment vérifier les permissions et surveiller les coûts cachés.

Ces compétences vous protègent à chaque fois que vous utilisez votre appareil.

Exercice pratique : Explorer l'App Store

  1. Ouvrez l'App Store et cherchez « MétéoMédia ». Vérifiez le nom du développeur, la note en étoiles et le nombre d'avis. Ne le téléchargez pas — c'est pour s'entraîner.
  2. Allez dans Réglages → [Votre Nom] → Abonnements et vérifiez si vous avez des abonnements actifs que vous ne connaissiez pas.
  3. Si vous avez des applications sur votre écran d'accueil que vous ne reconnaissez pas ou n'utilisez plus, entraînez-vous à en supprimer une.
Le succès ressemble à ceci : Vous pouvez rechercher une application en toute confiance, vérifier qu'elle est légitime en vérifiant le développeur et les évaluations, et vous savez où trouver et annuler les abonnements.

Vérification rapide : Testez vos connaissances

1. Quel est le seul endroit sûr pour télécharger des applications pour votre iPad ?

2. Une application demande la permission de « Suivre votre activité sur les applications et sites Web d'autres entreprises. » Que devriez-vous faire ?

3. Vous avez supprimé une application, mais vous êtes toujours facturé 9,99 $ par mois. Pourquoi ?
