Google Search Console — Setup Instructions

This file exists to remind you how to verify the Digital Confidence Centre with Google Search Console so Aaron can submit the sitemap and track search performance.

Step 1 — Get your verification code

  1. Go to search.google.com/search-console and sign in with your Google account.
  2. Click Add property.
  3. Choose URL prefix and enter:
    https://twobirds-kramerica.github.io/digital-confidence/
  4. Under Verify ownership, choose HTML tag.
  5. Copy the content value — it looks like:
    <meta name="google-site-verification" content="abc123XYZ456..." />

Step 2 — Replace the placeholder in index.html

Open index.html and find this line (near the top of <head>):

<!-- Google Search Console — replace REPLACE_WITH_REAL_CODE with real verification code -->
<meta name="google-site-verification" content="REPLACE_WITH_REAL_CODE" />

Replace REPLACE_WITH_REAL_CODE with the value Google gave you.

Step 3 — Commit and push

git add index.html
git commit -m "chore: Google Search Console verified"
git push origin main

Step 4 — Verify in Search Console

Go back to Search Console and click Verify. GitHub Pages usually deploys within 2–5 minutes, so wait a few minutes before verifying if it fails the first time.

Step 5 — Submit your sitemap

Once verified, go to Sitemaps in the left sidebar and submit:

sitemap.xml

The full sitemap URL is:
https://twobirds-kramerica.github.io/digital-confidence/sitemap.xml

The sitemap currently contains 107 URLs.
