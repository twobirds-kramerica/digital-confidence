🔗 Beta Invite URL Builder

Add these parameters to any page URL to tag the session as a beta test:

Base URL:

https://twobirds-kramerica.github.io/digital-confidence/?beta=true

Force A/B variant:

https://twobirds-kramerica.github.io/digital-confidence/?beta=true&ab_homepage-headline=variant-a

Start on specific module:

https://twobirds-kramerica.github.io/digital-confidence/module-3.html?beta=true

🐙 GitHub Issues Integration

Beta feedback submitted via the Formspree form is automatically tagged with the source module. To route feedback directly to GitHub Issues with beta-feedback label, configure a Zapier or Make (Integromat) workflow:

  1. Trigger: New Formspree submission
  2. Filter: Field is_beta = true (set via hidden form field when ?beta=true)
  3. Action: Create GitHub Issue with label beta-feedback
  4. Title: [Beta] {feedback_type} — {module}
  5. Body: Paste all form fields

Free tier of Make (Integromat) supports this workflow with no cost.
