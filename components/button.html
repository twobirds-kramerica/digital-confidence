Button Components

All buttons use .btn as the base class plus one variant. Minimum size: 60px (--tap-target). See DESIGN-SYSTEM.md for full rules.

Primary — Main call to action

<button class="btn btn-primary">Get Started</button> <button class="btn btn-primary btn-large">Start Module</button>

Secondary — Supporting action

<button class="btn btn-secondary">Go Back</button> <button class="btn btn-secondary btn-large">View All Modules</button>

Success — Completion / positive confirmation

<button class="btn btn-success">Mark as Complete ✓</button>

As a link — navigational button

Go to Dashboard Module 1
<a href="module-1.html" class="btn btn-primary">Go to Dashboard</a>

Print button — module footer

<button class="btn-print" onclick="window.print()" aria-label="Print this module">🖨 Print this module</button>

Disabled state

<button class="btn btn-primary" disabled aria-disabled="true">Unavailable</button>

Rules — never do these

  • ❌ Never use --accent-danger (red) for a primary action
  • ❌ Never make a button smaller than --tap-target (60px)
  • ❌ Never remove the :focus ring
  • ❌ Never use vague labels ("Submit", "Click Here")
  • ✅ Always use action verbs ("Save Changes", "Start Module", "Download Certificate")
