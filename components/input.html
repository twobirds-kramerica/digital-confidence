Form Input Components

Form styles are defined in this component file. Copy the CSS block from this file's <style> tag into any page that needs forms. Always pair every input with a visible label — never rely on placeholder text alone.

Text Input — standard

<div class="form-group"> <label class="form-label" for="your-field-id"> Field Label <span class="optional">(Optional)</span> </label> <input class="form-input" id="your-field-id" type="text" placeholder="Type here..."> </div>

Textarea — multi-line

Your feedback helps us improve the course for other seniors.

<div class="form-group"> <label class="form-label" for="feedback">Your Feedback</label> <textarea class="form-textarea" id="feedback" rows="4" placeholder="Tell us what you think..."></textarea> <p class="form-hint">Hint text here.</p> </div>

Select dropdown

<div class="form-group"> <label class="form-label" for="module-select">Which module?</label> <select class="form-select" id="module-select"> <option value="">-- Choose --</option> <option value="1">Module 1: ...</option> </select> </div>

Error state

⚠ Please enter a valid email address (for example: name@example.com)

<div class="form-group"> <label class="form-label" for="email">Email Address</label> <input class="form-input is-error" id="email" type="email" aria-describedby="email-error" aria-invalid="true"> <p class="form-error" id="email-error" role="alert"> ⚠ Please enter a valid email address </p> </div>

Field order per CLAUDE.md: Module → Feedback Type → Feedback → Submit → Your Name (Optional)

Rules

  • ✅ Always pair every input with a visible <label>
  • ✅ Minimum input height: var(--tap-target) (60px)
  • ✅ Minimum font size: 1rem (18px)
  • ✅ Show aria-invalid="true" and aria-describedby on error inputs
  • ✅ Use role="alert" on error messages so screen readers announce them
  • ✅ "Your Name" is always optional — label it Your Name (Optional)
  • ❌ Never use placeholder text as the only label
  • ❌ Never pre-populate name fields
  • ❌ Feedback form field order: do not change — Module → Type → Feedback → Submit → Name
